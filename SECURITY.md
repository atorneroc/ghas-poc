# Security Notice

Este repositorio contiene vulnerabilidades intencionales y valores ficticios para formación.

- No desplegar.
- No exponerlo como servicio.
- No añadir credenciales reales.
- No copiar los patrones vulnerables a proyectos productivos.
- Eliminar el repositorio después de la demostración si ya no es necesario.

Las correcciones esperadas para la discusión son:

- SQL parametrizado en lugar de concatenación.
- Actualización y prueba de dependencias.
- Revocación/rotación de secretos reales y uso de un gestor de secretos o identidad de carga de trabajo.
